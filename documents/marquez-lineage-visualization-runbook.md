# Marquez Lineage Visualization Runbook

Issue: #80 — Integrate Lineage Visualization (Marquez)  
Phase: 7 — Observability & Lineage

## Purpose

Use this runbook to validate that OpenLineage events generated by FraudLens appear correctly in Marquez.

## Prerequisites

- Local lineage JSONL events exist under `airflow/artifacts/observability/lineage/`.
- `MARQUEZ_BASE_URL` points to the Marquez API; `MARQUEZ_UI_URL` points to its separate web UI.
- `OPENLINEAGE_URL` points to the OpenLineage ingestion endpoint.

Example local defaults:

```powershell
$env:MARQUEZ_BASE_URL = "http://127.0.0.1:5002"
$env:MARQUEZ_UI_URL = "http://127.0.0.1:3004"
$env:OPENLINEAGE_URL = "http://127.0.0.1:5002/api/v1/lineage"
```

## Health Check

Capture Marquez API reachability:

```powershell
py scripts\check_marquez_health.py
```

Expected healthy result:

- `status` is `healthy`
- `status_code` is present
- `response_time_seconds` is captured

## Dry-Run Delivery Validation

Validate a lineage file before sending:

```powershell
py scripts\deliver_openlineage_to_marquez.py `
  --input airflow\artifacts\observability\lineage\pipeline\<run_stamp>\lineage_events.jsonl
```

Expected dry-run result:

- `dry_run` is `true`
- `event_count` is greater than zero
- each response includes `eventType`, `job`, and `runId`

## Send Events

Send events only after dry-run validation succeeds:

```powershell
py scripts\deliver_openlineage_to_marquez.py `
  --input airflow\artifacts\observability\lineage\pipeline\<run_stamp>\lineage_events.jsonl `
  --send
```

## UI Validation

These host ports apply to the current `fraudlens` container. Inside it, use API port `5000` and UI port `3000`. Check `docker port fraudlens` for other environments.

Open Marquez at `MARQUEZ_UI_URL` and validate:

1. namespace is visible
2. job appears for `fraudlens_pipeline_orchestration` or `dbt.model...`
3. run ID matches the delivered event
4. upstream input datasets are visible
5. downstream output datasets are visible
6. run facets include FraudLens metadata such as `batch_id`

## Troubleshooting

| Symptom | Check |
| --- | --- |
| Health helper returns `unreachable` | Confirm Marquez container/service is running and `MARQUEZ_BASE_URL` is correct. |
| Dry-run has zero events | Confirm the JSONL file exists and contains `openlineage_event` payloads. |
| Delivery fails | Confirm `OPENLINEAGE_URL` points to the OpenLineage ingestion endpoint. |
| UI has job but missing datasets | Inspect `inputs` and `outputs` in the delivered event. |
| Wrong namespace | Confirm `lineage_namespace` in `airflow/config/orchestration_profiles.yml`. |
